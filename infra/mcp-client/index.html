Globie Earth MCP client

This page is an MCP host. It talks to the Globie Earth server over Streamable HTTP with the official MCP SDK — the same code path an Alexa+ host uses — runs the initialize handshake, then lists and calls whatever the server advertises. The tool forms below are built from the JSON Schema the server returns, so nothing about the surface is hard-coded here.

1 · Connect

The device id is a uuid and is also the RevenueCat appUserID; the server's row-level security uses it to scope your deeds and balance. A demo bearer token, when the server has one configured, is exchanged at the edge for a demo device id — it is not MCP OAuth.
